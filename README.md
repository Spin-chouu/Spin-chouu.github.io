# Portfolio - Abdesalah Djessas

Portfolio statique prêt à être publié avec GitHub Pages. Aucune installation ni compilation n'est nécessaire.

## Publication sur GitHub Pages

1. Créez un dépôt GitHub public nommé `votre-pseudo.github.io`.
2. Déposez les trois fichiers de ce dossier à la racine du dépôt : `index.html`, `styles.css` et `script.js`.
3. Dans GitHub, ouvrez **Settings** → **Pages**.
4. Sous **Build and deployment**, choisissez **Deploy from a branch**, puis la branche `main` et le dossier `/(root)`.
5. Enregistrez. Après quelques minutes, le site sera accessible à `https://votre-pseudo.github.io`.

## Personnalisation rapide

- Ajoutez vos liens GitHub et LinkedIn dans `index.html` lorsque vous les aurez.
- Les cartes de projets sont construites à partir du CV et peuvent accueillir des liens vers les dépôts ou démos correspondants.
- L'adresse e-mail visible est `djessas.abdesalah@gmail.com`.
